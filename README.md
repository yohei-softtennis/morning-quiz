# 毎朝5問｜理科・社会（公開Webアプリ版）

中学3年生の高校受験対策クイズを、ブラウザで開けるWebアプリにしたものです。

- `/` プレイヤー画面（お子さん用）：あいことばでログイン。毎朝6:30に新しい5問（理科・社会、4択）。回答直後に解説カード（解説＋覚え方ポイント＋図解）。間違えた単元を記録し、苦手単元を優先出題。追加問題（さらに続ける）、週の正解率、単元別正答率、日曜の週末テスト（80%で合格、再テストあり）。
- `/admin` 管理画面（保護者用）：パスワード制。その日の結果・直近14日・単元別正答率・週末テスト履歴の確認、あいことばの設定、イロ連携トークンの発行。
- 連携API（`x-agent-token` ヘッダー認証）：毎朝の問題投入（本編5問＋追加プール）と、毎晩の結果取得に使います。

## 動かし方

```
node server.js   # PORT 環境変数、データ保存先は RAILWAY_VOLUME_MOUNT_PATH / DATA_DIR / アプリフォルダ
```

データは `quiz-data.json` に保存されます（Railwayでは永続ボリューム上に置きます）。
